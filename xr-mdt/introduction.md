Welcome to the **XR-MDT** documentation!

**XR-MDT** is an advanced, modular tablet system for FiveM servers, supporting multiple jobs (Police, EMS, DOJ, Businesses) within a single resource. It is designed for performance, aesthetics, and ease of configuration.

## Key Features
*   **Multi-Job Support:** LSPD, EMS, DOJ, and a Business system.
*   **Dynamic Dashboard:** Real-time statistics, wanted persons, and vehicle lookups.
*   **Citizen Records:** Manage citizen profiles, notes, licenses, and convictions.
*   **Vehicle Database:** Search for vehicles, mark as stolen/wanted.
*   **Incident System:** Create detailed incident reports with assigned offenders and evidence.
*   **Employee Management:** Hire, promote, and manage staff directly from the tablet.
*   **Integrated Dispatch:** Modern dispatch system with unit tracking on the map.
*   **Fully Editable:** Core framework logic is located in the `editable/` folder, allowing for easy adaptation.
