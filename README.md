## 🎯 About XR-Core

**XR-Core** is a development studio focused on creating premium, next-generation scripts for FiveM servers. We specialize in building high-performance, visually stunning tools designed with modern web technologies — including **React**, **Vite**, and **TypeScript** — to deliver the smoothest experience for both server owners and players.

Our products are fully compatible with the most popular frameworks — **QBCore**, **ESX**, and **Qbox** — and are built to integrate seamlessly into your existing server infrastructure.

> *"Innovating the Future of Gaming Infrastructure."*
